# Dawn 0.1.5.1 — Gateway fix

Gateway's final cannon could launch the player while its visual effect was off
and enemies were still alive. Its launch force now waits for the same final
encounter clear as its visual effect. Leaving one required enemy alive keeps
both inactive; defeating the final enemy releases both.

This release also includes the camera controls merged since 0.1.5: camera key
bindings in the Dawn menu and improved detection of function-key taps. File
logging is enabled in the default settings, and the package includes the
standalone Dawn uninstaller with its documentation.

## Install or update

Requires Destiny 2 build **86657.20.08.23.1800.d2_rc** and its complete game packages.

1. Download **Dawn-0.1.5.1.zip** under Assets and extract the whole ZIP.
2. Close Destiny 2.
3. Run **Update-Dawn.cmd** to keep your saves and settings. Use **Install-Dawn.cmd**
   only for a fresh profile.
4. Select the folder containing `destiny2.exe`, then launch the game normally.

Updates preserve existing logging preferences. New installations enable file
logging by default. The updater keeps a rollback backup under `.dawn/release-backups`.
The included **Uninstall-Dawn.cmd** permanently removes Dawn saves, settings,
caches and backups; it is only for completely removing Dawn.

## Validation

Gateway tests passed **275,760 checks in each of Debug and Release**, including
the one-enemy-alive regression and matching launch/VFX activation. The pinned
native force-accumulation boundary also passed its compatibility checks.

The defect was captured from a live session. The fix was built and installed
locally; a full in-game playthrough of the corrected encounter is still pending.
See **build-info.json** for source, binary and installer-test details, and
**SHA256SUMS.txt** for release asset checksums.
